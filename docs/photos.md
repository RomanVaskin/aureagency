# Фото для сайта AURE

Все фото сайта — в **одной папке** [`public/photos`](https://github.com/RomanVaskin/aureagency/tree/preview/public/photos) (ветка `preview`).

**[➜ Загрузить фото в папку](https://github.com/RomanVaskin/aureagency/upload/preview/public/photos)**

1. Назовите файл как в таблице ниже, например `kvartira-na-patriarshih-01.jpg`. Подходят `.jpg`, `.jpeg`, `.png`, `.webp`.
2. Откройте ссылку «Загрузить», перетащите файлы (можно все сразу, до 100 штук).
3. Внизу оставьте **Commit directly to the `preview` branch** и нажмите **Commit changes**.

Через ~2 минуты фото появятся на preview.aureagency.ru вместо серых заглушек. Файлы с другими именами сайт не увидит — их можно просто переименовать.

Всего мест под фото: 75. Промпты для генерации — в [`docs/image-prompts.md`](image-prompts.md).
