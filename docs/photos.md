# Фото для сайта AURE

Все фотографии сайта лежат в папке [`public/images`](https://github.com/RomanVaskin/aureagency/tree/preview/public/images) ветки `preview`.
Пока файла нет, на его месте показывается светлая заглушка. Как только фото загружено с нужным именем, оно появляется на preview.aureagency.ru после автоматического деплоя (~2 минуты).

## Как загрузить

1. Откройте ссылку «Загрузить» у нужной папки ниже (откроется GitHub, ветка `preview`).
2. Перетащите файлы в окно. **Имя файла должно совпадать с таблицей**, например `01.jpg`. Расширение может быть `.jpg`, `.jpeg`, `.png` или `.webp`.
3. Внизу выберите **Commit directly to the `preview` branch** и нажмите **Commit changes**.

Советы: ширина 2000–2400 px, JPG качество ~80 (обычно 300–800 КБ). Через сайт GitHub — до 25 МБ на файл и до 100 файлов за раз.
Промпты для генерации кадров — в [`docs/image-prompts.md`](image-prompts.md).
